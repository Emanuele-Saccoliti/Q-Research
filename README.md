# Q-Research

Quantitative research repository featuring ongoing applied projects driven by curiosity-based exploration:

- [Systematic Credit](SystematicCredit/README.md): bond-CDS basis trading, credit-curve calibration, systematic signals, hedging, backtesting, and dashboard export.
- [Copula Alpha Lab](CopulaAlpha_LAB/README.md): copula-based relative-value alpha research across liquid ETF pairs.
- [AI Macro Research](AI-macro-research/README.md): LLM and machine-learning pipeline for dynamic macro themes, regimes, and cross-asset research.
